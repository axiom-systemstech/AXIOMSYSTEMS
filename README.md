## 🚀 ¿Qué es AXIOM?

AXIOM es un lenguaje de programación diseñado para construir **todo tipo de software**:

- ✅ Aplicaciones
- ✅ Videojuegos
- ✅ Servidores
- ✅ Sistemas operativos
- ✅ IA
- ✅ Web
- ✅ Y más...

## ✨ Características

- 📌 **Sintaxis moderna** - Clara y expresiva
- 🏅 **Rendimiento extremo** - Compilado a código nativo
- 🔄 **Seguridad por defecto** - Sin accesos de memoria
- 🎯 **Concurrencia nativa** - Async/await, canales, actores
- 🌐 **Ecosistema completo** - Package manager, CLI, etc.

## 📦 Instalación

```bash
# Clonar el repositorio
git clone https://github.com/axiom-systemstech/AXIOMSYSTEMS.git
cd axiom-systems

# Compilar
cargo build --release

# Instalar (opcional)
cargo install --path .
```

🎯 Primeros pasos

```bash
# Crear un nuevo proyecto
axiom new mi-proyecto
cd mi-proyecto

# Ejecutar
axiom run src/main.ax

# Ver los tokens
axiom lex src/main.ax
```

📝 Ejemplo

```rust
// main.ax
fn main() {
    let message = "¡Hola, mundo!"
    println(message)
}
```
